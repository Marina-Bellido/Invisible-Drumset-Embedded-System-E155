Final Project for my Microprocessor Sys:Design & App Class

This was a joint project between Emmett Stralka (stremme1) and me, where we built an invisible drum set you can play in the air.

This project was developed without libraries, using pure embedded software in C and System Verilog. 
It implements two SPI and one I2C communication protocols, and employs embedded DSP (Digital Signal Processing) 
blocks to convert quaternion data to Euler angles for readable drum hits, alongside audio compression and unpacking 
using a DAC to play drum sounds. For this project, I utilized an MCU (STM32L432KC), an FPGA (UPduino v3.1), 
and two IMUs (BNO085) featuring 3-axis accelerometers, gyroscopes, and magnetometers onboard. 
The culmination of this work results in the creation of a drum set driven by embedded systems.
